## 📌 Overview

A data visualization project that transforms raw datasets into meaningful graphical representations. Clear and informative charts are produced to communicate patterns, trends, and comparisons effectively — making data accessible to both technical and non-technical audiences.

---

## 🎯 Objective

Create a comprehensive set of visualizations that tell a clear data story, covering distributions, comparisons, trends, and relationships.

## 📊 Visualizations Created

| Chart Type | Purpose |
|------------|---------|
| Scatter Plot | Relationship between two continuous variables |
| Histogram | Distribution of a single variable |
| Bar Chart | Category comparisons |
| Line Plot | Trend over a sequence |
| Box Plot | Distribution summary + outliers |
| Heatmap | Correlation matrix visualization |

---

## 🔬 Methodology

1. **Data Loading** — Import dataset using Pandas
2. **Chart Design** — Apply labels, titles, colour schemes, legends
3. **Multi-plot Layouts** — Use subplots for compact, comparative views
4. **Annotation** — Add data labels and reference lines where needed
5. **Export** — Save charts as `.png` for reports

---

## 📈 Key Outcomes

- Produced publication-quality charts from raw data
- Demonstrated how visual storytelling aids business decisions
- Compared multiple chart types for the same data — choosing the most appropriate
